# 422 Error

> **Source:** https://docs.shovels.ai/docs/knowledge-base/api/errors/422-error
> **Fetched:** 2026-04-16

## What it means

A 422 error indicates that **a required parameter is missing from your request**. In practice, the primary cause is querying permit endpoints without first converting an address into a `geo_id`.

## Root causes

**Missing `geo_id`.** Attempting to search permits without providing a `geo_id` triggers this error with the message:

> Invalid geolocation ID value. Have you resolved your address into Shovels geolocation ID?

**Malformed `geo_id`.** An incorrectly formatted `geo_id`, or one not obtained through proper address resolution, also triggers a 422.

## Step-by-step resolution

1. **Call Address Search first.** Submit address details (street, city, state) to `/v2/addresses/search`.
2. **Extract the `geo_id`** from the response.
3. **Query permits with `geo_id`:** `GET /v2/permits/search?geo_id=RESOLVED_GEO_ID`.
4. **Validate the response body.** Check error messages for any missing or invalid fields.

## Incorrect vs. correct

- **Incorrect:** `GET /v2/permits/search?street=123+Main+St` → returns 422.
- **Correct:** resolve via Address Search, then query permits with the returned `geo_id`.
