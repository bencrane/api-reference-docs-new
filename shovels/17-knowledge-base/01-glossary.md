# Glossary

> **Source:** https://docs.shovels.ai/docs/knowledge-base/glossary
> **Fetched:** 2026-04-16

Definitions of key terms used in Shovels permit, contractor, and decision data.

## A

- **Address ID** — Shovels identifier assigned to each location, enabling consistent linking of permits across different address formats.
- **AHJ (Authority Having Jurisdiction)** — The governmental body responsible for issuing building permits in a specific geographic area.
- **API Key** — A unique authentication token required to access the Shovels API. Pass in the `X-API-Key` header.
- **Active (Permit Status)** — A permit has been issued; work may proceed. Marked by the `issue_date` field.
- **Area Rezoning** — A zoning change applied to a larger geographic area, often initiated by municipalities as part of comprehensive planning.

## C

- **Contractor ID** — A unique identifier assigned by Shovels to each contractor. Deduplicated within individual states.
- **Contractor Group ID** — Identifier linking multiple contractors operating under the same parent organization.
- **CLI Config File** — A YAML configuration file at `~/.config/shovels/config.yaml` that stores persistent CLI settings.

## D

- **Decision (Shovels Decision)** — A structured record of a municipal zoning or land-use decision extracted from city-council and planning-department meetings.
- **Decision Category** — The classification of a zoning action type. Primary categories include Spot Rezoning, Area Rezoning, Zoning Code Modification, Special Use Permit.
- **Deduplication** — Process of identifying and consolidating duplicate records across permits and contractors.

## E

- **EDL (Enterprise Data License)** — Shovels' bulk data product for enterprise customers, delivering datasets to data warehouses monthly.
- **Exit Code (CLI)** — Numeric status code returned when a CLI command completes. Used by scripts and AI agents to determine success (0) or error type.

## F

- **File Date** — The date when a permit application was submitted to the jurisdiction.
- **Final (Permit Status)** — Project completion; passed final inspection.
- **Final Date** — The date when a permit received final approval after passing all required inspections.
- **First Seen Date** — The date when Shovels first discovered a permit in its data-collection process.

## G

- **geo_id** — A unified geographic identifier used by Shovels to link addresses to permit data. A `geo_id` can represent different geographic levels (address, zip code, city, state).
- **Geocoding** — The process of converting addresses into geographic coordinates (latitude and longitude).

## I

- **Inactive (Permit Status)** — Permit process has stalled due to failed inspections, expiration, or prolonged inactivity.
- **In Review (Permit Status)** — Application awaits approval.
- **is_representative** — Boolean field in EDL data indicating whether a contractor record is the primary representative of a contractor group.
- **Issue Date** — The date a permit was approved and issued by the jurisdiction, allowing construction work to begin.

## J

- **Jurisdiction** — The geographic area governed by a specific AHJ. Shovels covers approximately 2,000 jurisdictions.

## L

- **`--limit all`** — CLI flag that fetches all available records instead of the default 50-record limit.

## N

- **NAICS** — Modern industry classification system used to categorize businesses. More specific than SIC codes.
- **Newsworthiness** — Confidence score (0–1) in Shovels Decision data indicating the relevance and significance of a zoning decision.

## O

- **Over-the-Counter Permit** — Permit approved immediately without requiring follow-up inspections. Common for simple projects.

## P

- **Parquet** — Columnar data storage format optimized for analytics. Shovels EDL data is typically delivered as 15–20 GB Parquet files.
- **Permit ID** — A unique identifier generated by Shovels for each permit. Globally unique and persistent.
- **Permit Number (`permit_no`)** — The permit number assigned by the issuing jurisdiction. Not globally unique.
- **Primary Email** — Most frequently used email address across all permits for a given contractor.
- **Primary Phone** — Most frequently used phone number across all permits for a given contractor.
- **PUD (Planned Unit Development)** — Flexible zoning classification for master-planned projects that allows developers to negotiate custom development standards.

## R

- **API Credit Limit** — Maximum number of records you can retrieve via the API based on your paid plan.
- **API Rate Limit** — Technical limit on how quickly you can make API requests. Rate limits protect system stability.

## S

- **SIC** — Older industry classification system used to categorize businesses. More widely adopted than NAICS codes.
- **Special Use Permit** — Permission for activities not automatically allowed within a zone but approvable with conditions.
- **Shovels CLI** — Single-binary command-line tool for querying U.S. building permit and contractor data.
- **Shovels Online** — Web-based application for searching and downloading permit and contractor data.
- **Spot Rezoning** — Zoning change applied to a specific property or small group of parcels. Typically signals imminent development activity.
- **Start Date** — The first date recorded for a permit in Shovels' system.

## T

- **Tags** — Shovels-assigned categories that classify permits by work type (e.g., solar, HVAC, electrical, roofing).

## U

- **Unknown (Permit Status)** — Insufficient data to determine current permit state.

## V

- **Variance** — An exception to specific zoning requirements granted by a municipality for undue-hardship cases.

## Z

- **Zoning Code Modification** — Changes to zoning regulations themselves, rather than the zoning designation of specific properties.
