# Free Trial Guide

> **Source:** https://docs.shovels.ai/docs/knowledge-base/getting-started/free-trial-guide
> **Fetched:** 2026-04-16

## Request allowance

- **250 API requests.**
- **No credit card required.**
- Time limit: not specified (no time limit per the KB).

## What's included

- Full permit and contractor search functionality.
- All available filters (financial, building, permit, contractor categories).
- Contractor profiles and permit details.
- 250 API requests with full historical access.

## Historical data scope

- **Online interface:** last 12 months of data.
- **API:** full historical dataset, no date restrictions.

## Accessible features/endpoints

- Permit search.
- Contractor search.
- Filter and sort capabilities.
- Contractor profiles and permit details.

## Counting rule

Free trials use **request-based** counting: one API call = one unit regardless of records returned. Paid plans move to the record-based credit system (see `../14-api-basics/03-request-counts.md`).
