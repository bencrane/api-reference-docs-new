# Clay Overview

**URL:** https://docs.emailbison.com/low-code-tools/clay/overview

**Official EmailBison Integration (Recommended):**
EmailBison enrichments are available natively in Clay. To get started: Connect your workspace, Browse available enrichments.

**HTTP API Method (Alternative):**
The integration between EmailBison and Clay can also be done through the HTTP API (with headers) enrichment. If you haven't visited Low-Code Tools - Introduction yet, it provides a high-level overview of what to expect when translating API calls into the equivalent feature for low-code tools. The pages in this section will show step-by-step instructions, as well as accompanying videos. Although the steps are for specific requests, they can be easily altered to any other EmailBison endpoint. Every HTTP API enrichment will need to be authenticated, so make sure you follow Clay - Authenticating first.
