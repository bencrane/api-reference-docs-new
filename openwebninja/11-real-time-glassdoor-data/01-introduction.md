# Real-Time Glassdoor Data API Documentation

**Version:** v1.0.0
**Spec:** OAS 3.0.3

Complete reference documentation for the OpenWeb Ninja Real-Time Glassdoor Data API. Includes code examples, data samples, and usage guides for accessing company profiles, reviews, interviews, job postings, salary data, and more from Glassdoor.

## Server

```
https://api.openwebninja.com/realtime-glassdoor-data
```

## Authentication

**Required**

- **Selected Auth Type:** X-API-Key
- **API Key Name:** `x-api-key`

## Client Libraries

- Shell / Curl

## Operations

### default

- `GET /company-search`
