# USPS ZIP+4 | Geocodio API

**Field name:** `zip4`

**Coverage:** US only

Returns USPS ZIP+4 data including the full 9-digit ZIP code, carrier route, delivery type, and other postal delivery information. Requires API version v1.5 or newer.

## Request

```bash
curl "https://api.geocod.io/v1.12/geocode?q=1109+N+Highland+St%2C+Arlington+VA&fields=zip4&api_key=YOUR_API_KEY"
```

```bash
curl "https://api.geocod.io/v1.12/reverse?q=38.886672,-77.094735&fields=zip4&api_key=YOUR_API_KEY"
```

```json
{
  "fields": {
    "zip4": {
      "record_type": {
```

## Response Fields

### Record Type

The type of ZIP+4 result.

| Code | Description |
|---|---|
| `F` | Firm |
| `G` | General Delivery |
| `H` | High-rise |
| `P` | PO Box |
| `R` | Rural Route/Contract |
| `S` | Street |

### Residential Delivery Indicator (RDI)

`residential` is `true` for residential addresses and `false` for commercial addresses. Can be `null` if there are no records indicating the residential status.

### Carrier Route ID

A 4-byte code identifying the type of postal route:

| Prefix | Description |
|---|---|
| `Bxxx` | PO Box |
| `Hxxx` | Contract |
| `Rxxx` | Rural Route |
| `Cxxx` | City Delivery |
| `Gxxx` | General Delivery |

### Building or Firm Name

A USPS-provided name associated with the address. Available for businesses registered with USPS and most federal/state government buildings including schools and offices. Set to `null` if no name is available.

```json
"building_or_firm_name": "The Natl Capital Bank Of Washington"
```

### ZIP+4 and ZIP9

The ZIP+4 code(s) and full 9-digit ZIP code(s) associated with the result.

**Single code (most common):**
```json
"plus4": ["2890"],
"zip9": ["22201-2890"]
```

**Range for businesses:**
```json
"plus4": ["2890", "2900"],
"zip9": ["22201-2890", "22201-2900"]
```

**No code available (e.g., not a valid delivery area):**
```json
"plus4": [],
"zip9": []
```

### Government Building

Type of government building, if applicable. Set to `null` if not a government building.

| Code | Description |
|---|---|
| `A` | City Government Building |
| `B` | Federal Government Building |
| `C` | State Government Building |
| `D` | Firm Only |
| `E` | City Government Building and Firm Only |
| `F` | Federal Government Building |
| `G` | State Government Building and Firm Only |

```json
"government_building": {
  "code": "B",
  "description": "Federal Government Building"
}
```

### Facility Code

Facility code associated with the 5-digit ZIP code.

| Code | Description |
|---|---|
| `B` | Branch |
| `C` | Community post office (CPO) |
| `N` | Non-postal community name, former USPS facility, or place name |
| `P` | Post Office |
| `S` | Station |
| `U` | Urbanization |

### City Delivery Indicator

`city_delivery` indicates whether the local post office has a city delivery carrier route.

### Valid Delivery Area

`valid_delivery_area` indicates whether the address is a valid delivery point. Some addresses exist but are not valid for postal delivery (e.g., undeveloped lots).

### Exact Match

`exact_match` is `true` when there is no ambiguity with the lookup and the ZIP+4 code is the only correct match. Non-exact matches often occur for apartment/office buildings missing a unit number, where an accurate ZIP+4 cannot be determined without secondary address information.

## Notes

If no ZIP+4 data is available for the given query, the `zip4` field is omitted from the JSON output entirely, and the field lookup does not count against your usage.
