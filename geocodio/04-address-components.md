# Address Components | Geocodio API

## Address Components

Geocodio parses and standardizes all address results. Every result includes an `address_components` object. Keys are only present when a valid value exists for that component.

| Key | Description |
|---|---|
| `number` | House number, e.g. `"2100"` or `"250 1/2"` |
| `predirectional` | Directional before the street name, 1-2 characters, e.g. `N` or `NE` |
| `prefix` | Abbreviated street prefix, common in French addresses, e.g. `Rue`, `Boulevard`, `Impasse` |
| `street` | Street name without number, prefix, or suffix, e.g. `"Main"` |
| `suffix` | Abbreviated street suffix, e.g. `St.`, `Ave.`, `Rd.` |
| `postdirectional` | Directional after the street name, 1-2 characters, e.g. `N` or `NE` |
| `secondaryunit` | Name of the secondary unit, e.g. `"Apt"` or `"Unit"`. Returned for input address components only |
| `secondarynumber` | Secondary unit number. Returned for input address components only |
| `city` | City name |
| `county` | County name |
| `state` | State abbreviation |
| `zip` | 5-digit zip code for US addresses. The 3-character FSA is returned for Canadian results (full postal code is not returned) |
| `country` | Country code |
| `formatted_street` | Fully formatted street including all directionals and suffix/prefix, but not the house number |

### Example Response

```json
{
  "address_components": {
    "number": "1109",
    "predirectional": "N",
    "street": "Highland",
    "suffix": "St",
    "formatted_street": "N Highland St",
    "city": "Arlington",
    "county": "Arlington County",
    "state": "VA",
    "zip": "22201",
    "country": "US"
  }
}
```

## Accuracy Score

Each geocoded result includes an `accuracy` score -- a decimal number ranging from `0.00` to `1.00`. The score is generated by the Geocodio engine based on how accurate the result is believed to be. Higher scores indicate better results. Results are always returned ordered by accuracy score.

If an address cannot be found precisely, Geocodio returns a geocoded point based on the postal code or city with a lower accuracy score and `accuracy_type` set to `"place"`.

As a general guideline, accuracy scores >= `0.8` are the most accurate. Results with lower scores may be rough matches.

An `accuracy_type` is also returned with all results. We recommend using a combination of the accuracy score and accuracy type to evaluate and filter results.

### Forward Geocoding Accuracy Types

| Value | Description |
|---|---|
| `rooftop` | The exact point was found with rooftop-level accuracy |
| `point` | The exact point was found from address range interpolation where the range contained a single point |
| `range_interpolation` | The point was found by performing address range interpolation |
| `nearest_rooftop_match` | The exact house number was not found, so a close, neighboring house number was used instead |
| `intersection` | The result is an intersection between two streets |
| `street_center` | The result is a geocoded street centroid |
| `place` | The point is a city/town/place or zip code centroid |
| `county` | The point is a county centroid |
| `state` | The point is a state centroid |

### Reverse Geocoding Accuracy Types

| Value | Description |
|---|---|
| `rooftop` | The exact point was found with rooftop-level accuracy |
| `nearest_street` | Nearest match for a specific street with estimated street number |
| `nearest_place` | Closest city/town/place |

## Match Type

All geocoding results include a `match_type` field that indicates the type of coordinate match. This field provides additional granularity beyond `accuracy_type` and can help you understand the source of the returned coordinates.

Unlike `accuracy_type`, the `match_type` value can be `null` when no specific match type information is available.

| Value | Description |
|---|---|
| `building_centroid` | Coordinates derived from a building footprint centroid. Pairs with `rooftop` and `nearest_rooftop_match` accuracy types |
| `parcel_centroid` | Coordinates derived from a property parcel centroid. Pairs with `rooftop` and `nearest_rooftop_match` accuracy types |
| `unit` | Unit-level coordinates from secondary address line geocoding. The result has been matched to a specific apartment, suite, or unit within a building |
| `null` | No specific match type information is available. Can apply to any accuracy type, including `rooftop` results where the coordinate source type is not known, as well as `range_interpolation`, `street_center`, `place`, and other result types |

The `match_type` field is additive and does not change the behavior of existing `accuracy_type` values. It is returned for all API versions.

### Example Response with All Fields

```json
{
  "results": [
    {
      "address_components": {
        "number": "1109",
        "predirectional": "N",
        "street": "Highland",
        "suffix": "St",
        "formatted_street": "N Highland St",
        "city": "Arlington",
        "county": "Arlington County",
        "state": "VA",
        "zip": "22201",
        "country": "US"
      },
      "formatted_address": "1109 N Highland St, Arlington, VA 22201",
      "location": {
        "lat": 38.886665,
        "lng": -77.094733
      },
      "accuracy": 1,
      "accuracy_type": "rooftop",
      "match_type": "building_centroid",
      "source": "Virginia GIS Clearinghouse"
    }
  ]
}
```
