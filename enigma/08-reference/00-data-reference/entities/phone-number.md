A phone number associated with a particular business entity. Phone numbers are standardized
to a twelve-digit NANP-compliant format (for example, "+19175362876") and must have a valid U.S. area code.
GraphQL type: PhoneNumber
ExampleThe number (206) 447-1575 is a Phone Number entity linked to a Starbucks operating location.
