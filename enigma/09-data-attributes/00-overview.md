# Enigma Data Attribute Reference

> https://documentation.enigma.com/reference/attributes/

## Overview

Enigma structures business information into **attributes**—discrete data elements such as names, addresses, revenue figures, and industry categories. Each attribute connects to an **entity** type: Brand, Legal Entity, or Operating Location.

## Key Concept

According to the documentation, "Enigma organizes business data into **attributes** - structured data points like names, addresses, revenue metrics, and industry classifications."

## Attributes Organized by Entity Type

The reference groups 33 total attributes across 16 entity types:

### Brand Entity
- Brand Activity (Plus tier)
- Brand Location Description (Core)
- Brand Revenue Quality (Plus)
- Card Transactions—Brand (Plus)
- Is Marketable—Brand (Core)
- Name (Core)

### Legal Entity
- Bankruptcy (Premium)
- Name (Free)
- Type (Free)

### Operating Location
- Card Transactions—Operating Location (Plus)
- Is Marketable—Operating Location (Core)
- Name (Core)
- Location Type (Core)
- Revenue Quality (Plus)
- Operating Status (Core)
- Rank (Plus)
- Technologies Used (Premium)

### Shared Attributes (Across Multiple Entities)
- Address (Core)
- Address Deliverability (Plus)
- Email Address (Core)
- Phone Number (Core)
- Industry (Core, Brand only)
- Person Name (Core, Legal Entity)
- Registered Entity (Premium)
- Registration (Premium)
- Review Summary (Plus, Operating Location)
- Role (Plus)
- Taxpayer ID (Premium, Legal Entity)
- Watchlist Entry (Premium)
- Website (Core)
- Website Content (Plus)
- Online Presence (Core)
- Website Technologies Used (Premium)
