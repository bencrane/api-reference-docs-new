# Enigma Console Documentation - Overview

> https://documentation.enigma.com/console/

## Summary

The Enigma Console serves as the primary web interface for accessing business data and managing organizational accounts. It enables users to search businesses, build lead lists, enrich customer data, and configure account settings.

## Key Capabilities

**Data Exploration:**
- "Look up specific brands, legal entities, or persons and view detailed profiles"
- Create targeted business segments using filters
- Upload and append Enigma attributes to existing records
- Test GraphQL queries via built-in API Playground

**Account Management:**
- Team member invitations and role assignment
- S3 or SFTP storage connection for batch workflows
- SAML authentication configuration
- Workspace organization (Enterprise feature)
- Credit usage monitoring and invoice management

## Accessing API Credentials

Users can retrieve API keys through **Settings > Account > API Keys**. Enterprise organizations with workspaces may have multiple workspace-scoped API keys.

## Profile Updates

Profile modifications occur via **Settings > Account > Preferences**, where users can update their name. Password changes use the Security section's dedicated button. Email address changes require contacting support@enigma.com.

## Navigation Structure

Settings are organized into three groups: Account, Access, and Billing, with documentation using the format **Settings > Group > Page**.
