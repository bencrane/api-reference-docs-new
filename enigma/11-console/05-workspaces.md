# Enigma Console Workspaces Documentation

> https://documentation.enigma.com/console/workspaces

## Overview

Workspaces enable organizations to "organize your organization's users and API keys into separate groups." Each workspace maintains isolated API keys and user access controls for improved permission management across teams or projects.

**Availability Note:** This feature requires an Enterprise plan. Organizations without Workspaces visibility in Settings should contact their Enigma representative.

## Viewing Workspaces

Access the workspace list by navigating to **Settings > Access > Workspaces**. All organizational workspaces display sorted by creation date.

## Creating a Workspace

Only organization Admins and Owners may create workspaces:

1. Go to **Settings > Access > Workspaces**
2. Select **Add Workspace**
3. Enter a workspace name
4. Click **Confirm**

## Managing Workspace Users

### Adding Users

1. Navigate to **Settings > Access > Workspaces** and select the target workspace
2. Click **Add Users**
3. Select desired users
4. Click **Confirm**

### Removing Users

1. Go to **Settings > Access > Workspaces** and select the workspace
2. Locate the user in the list
3. Click the actions menu (three dots)
4. Select **Remove**

## Managing Workspace API Keys

Each workspace supports independent API key management.

### Creating API Keys

1. Navigate to **Settings > Access > Workspaces** and select a workspace
2. Click **Add API Key**
3. Name the key
4. Click **Confirm**
5. Copy the key immediately—full display occurs only once for security

### Revoking API Keys

1. Go to **Settings > Access > Workspaces** and select a workspace
2. Find the API key
3. Click the actions menu
4. Select **Revoke**

**Warning:** "Revoking an API key is permanent. Any applications using the revoked key will immediately lose access."
