# Study Data Structure

## Introduction

The information below shows study data fields and their data type and other JSON attributes.

- "Piece Name" and "Alt Piece Names" are unique, so a field can be referenced by them.
- Fields marked with ⤷ start nested documents, which allow use of a SEARCH operator to target search results. For example, this query matches city, state, and country inside one location: SEARCH[Location](AREA[LocationCity]Florence AND AREA[LocationState]South Carolina AND AREA[LocationCountry]United States)
- Fields marked with ✗ are available for search but not for retrieval.
- Fields producing synonyms are marked with ✓.
